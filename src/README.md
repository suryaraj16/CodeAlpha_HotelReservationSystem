## Project Description
The Hotel Reservation System is a Java-based console application developed to manage hotel room bookings efficiently. The system allows users to view available rooms, book rooms, cancel reservations, and manage room details using Object-Oriented Programming concepts.

---

## Features
- View available and booked rooms
- Book hotel rooms
- Cancel room reservations
- Room categorization (Standard, Deluxe, Suite)
- Payment simulation
- User-friendly console interface

---

## Technologies Used
- Java
- OOP Concepts
- ArrayList
- Scanner Class
